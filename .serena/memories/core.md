# adapt_x — Core

- ROS 2 Humble adaptation engine package with Java/Xtext/JPype model integration.
- Runtime Python modules: `adapt_x/adapt_x/`; ROS interfaces: `adapt_x_msgs/`; tests: `adapt_x/test/`.
- Read `mem:proxy_action_server` for batched feature actions, no-op behavior, dynamic adaptation timing, terminal failures, and Humble executor constraints.
